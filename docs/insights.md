# Insights Gained

Adding explicit linting and TypeScript validation rules shifted the
agent’s behavior from "producing working code" to "producing
production-ready code."

The rules influenced how the agent:
- Planned function signatures
- Considered edge cases earlier
- Avoided risky or ambiguous typing decisions

By encoding my expectations around code quality and safety,
the agent’s responses began to align more closely with my own
development standards and reasoning process.

This demonstrated that even a small, focused rules change can
significantly influence agent behavior.
